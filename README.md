# Objektservice Bayern

Eine mobilfreundliche Website für Objektservice Bayern / HR Hausmeisterservice Reisich.

## Ziel
- Leistungen übersichtlich präsentieren
- Interessenten durch eine einfache Anfrage führen
- Angaben zu Objekt, gewünschter Arbeit und Kontakt strukturiert erfassen
- Eine übersichtliche Anfrage-Zusammenfassung erzeugen

## Geplante Umsetzung
Die Website wird unabhängig von Lovable entwickelt und in diesem GitHub-Repository versioniert.

## Hinweis
Kontaktangaben, Einsatzgebiet und verbindliche Leistungsangebote werden erst veröffentlicht, wenn sie vom Betreiber bestätigt wurden.
